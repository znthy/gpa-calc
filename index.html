How it is calculated

A = 5 (70–100) · B = 4 (60–69) · C = 3 (50–59) · D = 2 (45–49) · E = 1 (40–44) · F = 0 (0–39)

Credit points for a course = units × grade point. TCP is all the credit points added up, TLU is all the units added up, and GPA = TCP ÷ TLU. CGPA is the same sum over every semester together.
